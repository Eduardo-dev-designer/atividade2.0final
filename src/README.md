# Laticínios Bom Leite

Aplicativo de divulgação de produtos e promoções feito com React Native + TypeScript + Expo Router.

## Telas
- Menu principal
- Listagem de 10 produtos com nome, preço e unidade
- Listagem de 6 promoções com nome, tipo, preço promocional e foto

## Como executar
1. Instale o Node.js LTS.
2. Extraia o ZIP e abra a pasta do projeto no VS Code.
3. No terminal, execute `npm install`.
4. Execute `npx expo start`.
5. Leia o QR code com o Expo Go ou pressione `w` para abrir no navegador.

As imagens são carregadas por URLs da internet; é necessário ter conexão para visualizá-las.
Os preços e as promoções são exemplos fictícios para a atividade.
